# Security

This repository contains an unsupported engineering Preview, not a supported Login Enterprise feature.

Do not publish raw Login Enterprise Engine logs, authentication/session data, credentials, tokens, environment details, or unreviewed screenshots. Logs can contain sensitive material even when the placement failure itself is harmless. Keep local diagnostics under the ignored `artifacts/` directory and share only minimized, reviewed evidence through Login VSI's established private security/reporting or support contact process.

Do not open a public issue containing a suspected vulnerability or sensitive diagnostic data. This repository does not establish a new security email or support entitlement.
