# Reference material

This directory holds source evidence supplied for later engineering. Its subdirectories distinguish immutable baseline workloads, proven proof-of-concept code, authoritative Login Enterprise documentation/examples, and scenario configuration evidence.

Reference material is not automatically safe to publish merely because it is placed here. Review it for public safety before committing. Follow each subdirectory's preservation rules.

Use `scripts/Verify-ReferenceHashes.ps1 -Verify` for immutable original workloads and `scripts/Verify-PreservedEvidenceHashes.ps1 -Verify` for proven POC source plus the authoritative `workload-sequence.txt` transcription. The supporting scenario PNG is intentionally outside the preserved-evidence manifest.
